# ログ更新

このスクリプトは、現在の「我らのあそび場」の暗号化データを**差分更新**します。

ユーザー側の運用は、ChatGPT に次のどちらかを渡して「ログ更新して」でOKです。

- 最新の `_chat.txt` ファイル
- 新しく増えた部分だけをベタ貼り

ベタ貼りはこの形式です。

```text
[2026/09/23 18:25:34] ぱっち: い）
[2026/09/23 18:25:43] ぱっち: ぱくっ
[2026/09/23 18:26:38] motchi: 読んで満足されたら生身の価値、、、ｪ
```

複数行メッセージにも対応しています。`state.json` の最終更新時刻より後だけを処理するため、全文ファイルを何度渡しても二重登録しません。

## 実行

```bash
python3 scripts/update_log.py _chat.txt
```

ベタ貼りなら標準入力でも実行できます。

```bash
python3 scripts/update_log.py
```

合言葉はリポジトリに保存しません。実行時入力、または環境変数 `WARERA_PASSPHRASE` を使用します。

## 自動更新するもの

- われわれ統計
- われわれ国語辞典（既存語の回数・例文）
- われわれ検定（新しい問題候補）
- たまには思い出そうず
- あの日のわれわれ（思い出データの日付を利用）

新しい辞書語の「語義」だけは機械的に決めず、必要なときにAI側で候補を追加します。
